# Salutte Elevate

Crie um site institucional moderno, sofisticado e responsivo para a Salutte Clinic e Estética Avançada, uma clínica especializada localizada em Caldas Novas – GO.

Objetivo do site

O site deve transmitir sofisticação, confiança, acolhimento, profissionalismo e excelência, apresentando a Salutte como uma clínica de estética avançada com atendimento humanizado e ambiente premium.

O principal objetivo é fazer com que visitantes conheçam os serviços e entrem em contato pelo WhatsApp para agendar uma avaliação ou procedimento.

Importante

Não deixar o site com aparência de template genérico de clínica.

A sensação deve ser de uma marca premium, sofisticada e confiável, semelhante a uma clínica de estética de alto padrão.

Priorizar:
elegância + confiança + acolhimento + conversão.

Não inventar informações médicas, certificações, profissionais, procedimentos, preços ou resultados.

Todo conteúdo que não foi confirmado deve ser criado como conteúdo editável/placeholders.

Utilizar uma arquitetura moderna e componentes reutilizáveis para que a equipe da clínica possa posteriormente alterar textos, imagens, procedimentos, profissionais e informações de contato com facilidade.
